# NL2KE
# 基于词语出现频率的算子关键词匹配流程

这是一个基于词语出现频率的算子关键词匹配的训练、验证、测试流程代码。代码除了基本的 Python 库外，还需用到 `nltk` 库，用于长语句分词。

如果想试用，可以将代码下载到本地，运行 `test_weight.py`，即可查看当前知识方程算子-关键词匹配的水平。`train` 文件夹中的 `PDFQ.json` 文件包含了训练集中所有问题的知识方程形式，共计 38400 个。为了降低训练或验证时的设备要求、提升速度，可以按需将数据分成多个小部分处理。例如，`batch_100per` 文件夹中即为按 100 个一组分开的数据部分，也可根据其他原则灵活安排数据使用。

## 代码详解

以下是核心代码文件及其功能：

- **`enhance_dictionary_fixed.py`**：用于加强算子-关键词匹配数据集（`fixed_Declaration.json` 和 `fixed_others.json`）的程序。该程序基于 `test_weight.py` 得到的反馈，根据匹配正确和错误的词，按照固定增幅（或减少）调整相应词语的权重。

- **`enhance_dictionary_dinamic.py`**：功能与 `enhance_dictionary_fixed.py` 类似，但权重调整算法改为基于匹配错误或匹配缺少的频率动态计算。

- **`match_operators.py`**：使用已生成的算子-关键词匹配文件，对无标签的问题列表进行实际匹配，输出每个问题可能用到的知识方程算子。输入为一个问题列表。

- **`test_weight.py`**：用于训练、更新和验证算子-关键词匹配文件。输入为带有知识方程标签的数据以及已构建的算子-关键词对应数据集。程序将算子分为“定义”和“其他”类型分别进行匹配和训练，以提高匹配准确率（理论上，分类越精细，准确率可能越高）。

## Data 文件夹内容

Data 文件夹包含以下数据集：

- **测试集**：包含三个数据集，每个约 270 条数据，可用于测试。
- **训练集**：
  - `train(PDFQ).json`：包含 38400 个题目，知识方程标注完整。
  - `train(PDFQL).json`：包含完整知识方程及 Lean4 语言的数据集。
  - `train(only P).json`：仅包含问题（problem）的数据集。
  - 附有代码可将常规完整数据转化为以上类型。若数据量过大难以在本地运行，还可通过 `desperate.py` 将数据集切分为自定义大小的若干文件。
- **Operator 数据**：本流程的核心目标数据，用于通过权重实现算子和关键词的匹配。

## Initialize 文件夹内容

此文件夹包含生成初始算子和关键词的程序，步骤如下：

1. **`Assertional_Logic_out.py`**：从带有 `declaration`、`facts`、`query` 标签的数据集中提取可能的算子。
2. **`word_keyword.py`**：基于有标签的数据，通过分词统计词频，初步生成算子-关键词匹配（词级别）。
3. **`phrase_keyword.py`**：从有标签的数据中初步生成算子-关键词匹配（短语级别）。
4. **`deepseek-r1.py`**：调用大模型进行补充匹配。
5. **`phrase2word.py`**：将大模型生成的短语型关键词拆分为词。
6. **`combine.py`**：合并词级别和短语级别的匹配结果，最终生成初步的算子-关键词匹配文件。

> 注意：由于是初步筛选，所有权重均控制在 15 以内，以便后续加强调整。
